# 🌐 Autonomous Site Empire Portfolio

An autonomous network of niche directory websites. Automated daily via **GitHub Actions** and **Google Gemini 2.5 Flash**.

- **Automation Engine:** [Daily Factory Workflow](https://github.com/jibranpcccc/site-empire-factory/actions)
- **Schedule:** Runs daily at **06:00 UTC (11:00 AM PKT)**
- **Daily Limit:** Exactly 3 websites per day
- **Google Search Console:** Auto-verified via `google6fe267a998c19a9a.html`
- **Instant Search Indexing:** IndexNow API connected (`HTTP 202 Accepted`)
